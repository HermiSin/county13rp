# Sicherheitsmeldungen

Dieses Repository ist öffentlich. Sicherheitslücken und versehentlich veröffentlichte Zugangsdaten werden dem Repository-Inhaber **HermiSin** über einen bereits bekannten privaten Kontakt gemeldet. Falls GitHub hier eine private Sicherheitsmeldung anbietet, kann diese verwendet werden. Die Verfügbarkeit dieser Funktion ist nicht vorausgesetzt.

Keine Exploitdetails, Zugangsdaten oder personenbezogenen Daten in öffentlichen Issues oder Pull Requests veröffentlichen.

Bei offengelegten Zugangsdaten müssen die betroffenen Zugänge widerrufen oder erneuert werden. Das Löschen einer Datei allein entfernt ihren Inhalt nicht aus der Git-Historie.

Geschützte Projektunterlagen und produktive Konfigurationen bleiben außerhalb dieses Repositorys. Die `.gitignore` ist eine zusätzliche Hilfe; vor jedem Commit müssen die tatsächlich aufgenommenen Dateien geprüft werden.
