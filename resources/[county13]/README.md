# Eigene County-13-Ressourcen

Hier werden eigene FiveM-Ressourcen mit dem Präfix `c13_` aufgenommen. Aktuell ist noch keine eigene Ressource implementiert.

Pro Ressource werden Zweck, Abhängigkeiten, Konfiguration, Berechtigungen und durchgeführte Prüfungen dokumentiert. Client, Server und gegebenenfalls NUI werden innerhalb der jeweiligen Ressource getrennt. Produktive Daten und Zugangsdaten gehören nicht in diesen Ordner.
