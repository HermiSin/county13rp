# County 13

Offizielles Repository des deutschsprachigen FiveM/GTA-V-Roleplay-Projekts **County 13**.

County 13 verbindet ländlichen Alltag, zivile Berufe und langfristiges Charakterspiel mit einer gemeinsamen Mystery-Geschichte. Schauplatz sind Sandy Shores, Grapeseed und das angrenzende Umland. Jeder Charakter kann wichtig werden: durch Arbeit, Beziehungen und Entscheidungen.

## Projektstand

Das Projekt befindet sich im Aufbau. Eine FiveM-Installation mit Qbox besteht laut interner Betriebsdokumentation bereits. Dieses Repository beginnt mit öffentlichen Projektunterlagen und einer Struktur für eigene Ressourcen; es enthält noch keinen vollständigen spielbaren Server und keine Kopie des produktiven Servers.

- Website: [county13rp.com](https://county13rp.com/)

## Struktur

```text
docs/                    Öffentliche Lore und Entwicklungsunterlagen
resources/[county13]/    Eigene FiveM-Ressourcen, sobald implementiert
config/                  Konfigurationsbeispiele ohne Zugangsdaten
.github/                 Vorlagen für Issues und Pull Requests
```

## Mitarbeit

Fehler und Vorschläge werden über GitHub Issues gesammelt. Änderungen erfolgen über kurze Arbeitsbranches und Pull Requests nach [CONTRIBUTING.md](CONTRIBUTING.md). Neue Ideen sind Vorschläge, bis sie vom Projekt beschlossen wurden.

Dieses Repository ist öffentlich. Interne Story-Unterlagen, reale Spielerinformationen, Betriebszugänge und produktive Konfigurationen gehören ausschließlich in geschützte Ablagen. Siehe [SECURITY.md](SECURITY.md).

County 13 ist eigene Serverfiktion und kein offizielles Projekt von Rockstar Games. Rechte und Nutzungshinweise stehen in [NOTICE.md](NOTICE.md).
